## Talk 1: Doing mathematics differently

Are you confident that your proofs are correct? Lean is an open-source programming language that helps you verify them. In this first of two talks, we will explore what it means to formally verify a mathematical proof. We will focus on type theory, an alternative to set theory in which statements resemble sets, and proving a statement amounts to showing that the corresponding set is non-empty. Type theory is the foundation of most interactive theorem provers, including Lean, which we will use throughout this talk and the next.

## Talk 2: A tactical game

Formally verifying a proof by writing out the proof term is often impractical. In practice, Lean users rely on tactics: predefined commands that simplify the problem, making it easier to build a proof from already verified results. In this talk, we will go through some of the most basic, and most frequently used tactics in the Lean community, and see how to use them to prove some elementary results.
